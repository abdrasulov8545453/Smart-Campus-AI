# Smart Campus AI — учебный проект

## Описание
Smart Campus AI — адаптивная веб-платформа для демонстрационного мониторинга инфраструктуры учебного кампуса. Интерфейс и данные на русском языке.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере. Для наиболее стабильной работы рекомендуется запуск через локальный веб-сервер или расширение Live Server.
3. На странице входа можно использовать демонстрационные значения: `admin@campus.edu` / `campus123`. Вход учебный и не обеспечивает реальную аутентификацию.
4. Данные помещений, устройств, заявок и тема интерфейса сохраняются в `localStorage` браузера.

## Реализовано
- Демонстрационная форма входа и выбор роли.
- Dashboard с KPI и тремя графиками Chart.js.
- 12 помещений с поиском и фильтрами.
- 20 IoT-устройств, статусы online/offline и добавление устройства.
- CRUD для заявок: создание, редактирование, удаление и смена статуса.
- Уведомления и отметка прочтения.
- AI Analytics: пороговые правила, Z-score и рекомендации.
- Светлая/тёмная тема с сохранением выбора.
- Настройки кампуса и сброс тестовых данных.
- Адаптивная вёрстка для компьютеров и мобильных устройств.

## Структура
- `index.html` — структура интерфейса.
- `assets/css/style.css` — стили и адаптивный дизайн.
- `assets/js/data.js` — исходные демонстрационные данные.
- `assets/js/app.js` — навигация, фильтры, графики, CRUD, аналитика и localStorage.

## Ограничения
Это учебный фронтенд-прототип. Датчики имитируются, а AI-модуль использует правила и статистический метод, а не генеративную модель. Реальные учётные записи, серверная база данных и защищённая аутентификация не подключены. Chart.js загружается через CDN, поэтому для графиков требуется подключение к Интернету.
